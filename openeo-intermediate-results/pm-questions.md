# OpenEO 中间结果下载:需求确认(精简版)

> 背景:OpenEO 默认只返回最终结果。要提供中间结果,做法是让流程中指定的步骤也输出文件(`save_result`),任务完成后与最终结果一起下载。
> 下面 9 题按"输入输出 → 处理逻辑 → 使用场景"组织,每题勾选即可。

## 一、输入与输出(要什么、什么格式)

**1. 需要下载哪些中间结果?(可多选)**
- [ ] 预处理后的数据(去云、重投影等)
- [ ] 指数/特征层(如 NDVI)
- [ ] 时间合成/聚合结果
- [ ] 模型或分类的中间产物
- [ ] 所有步骤都要

**2. 输出文件格式?**
- [ ] GeoTIFF / COG(推荐)
- [ ] NetCDF / Zarr(多维时间序列)
- [ ] 矢量类还需 GeoJSON / GeoPackage

**3. 单次任务中间结果大概多大?**
- [ ] 小于 1 GB
- [ ] 1 GB – 50 GB
- [ ] 50 GB 以上

## 二、处理逻辑(怎么产出、怎么描述)

**4. 由谁决定哪一步要输出?**
- [ ] 用户提交任务时自己指定(推荐)
- [ ] 系统对固定流程预先配置好
- [ ] 全部输出,用户事后挑选

**5. 什么时候拿到?**
- [ ] 任务完成后一起下载(推荐)
- [ ] 运行中某一步完成就能下载

**6. 是否需要 STAC 目录?**
- [ ] 不需要,给文件列表即可
- [ ] 需要:每次任务结果自带 STAC 描述(OpenEO 批处理已支持,成本低)
- [ ] 需要:还要入库到 STAC 服务,供检索和跨任务复用(需额外部署,工作量大)

## 三、使用场景(谁用、怎么用、用多久)

**7. 中间结果拿来做什么?**
- [ ] 仅查看/核对结果,调试流程
- [ ] 下载后在本地其他软件继续分析
- [ ] 作为下一次 OpenEO 任务的输入复用

**8. 谁可以下载?**
- [ ] 仅提交任务的本人(推荐)
- [ ] 同团队/项目成员
- [ ] 所有登录用户

**9. 保留多久?**
- [ ] 7 天
- [ ] 30 天(推荐)
- [ ] 手动删除前一直保留

---
**默认建议(无明确意见时):** 用户自选输出步骤,任务完成后下载 COG,每次结果自带 STAC 描述,仅限本人,保留 30 天;STAC 入库和"运行中下载"放二期。
