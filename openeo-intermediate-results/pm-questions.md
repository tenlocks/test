# OpenEO 中间结果下载:需求确认(精简版)

> 背景:OpenEO 默认只返回最终结果。要提供中间结果,做法是在流程中让指定步骤也输出文件(`save_result`),作业完成后与最终结果一起下载。下面 9 个问题用来确认范围,每题勾一个(或按注明多选)即可。

**1. 需要下载哪些中间结果?(可多选)**
- [ ] 预处理后的数据(去云、重投影等)
- [ ] 指数/特征层(如 NDVI)
- [ ] 时间合成/聚合结果
- [ ] 模型或分类的中间产物
- [ ] 所有步骤都要

**2. 由谁决定哪一步要输出?**
- [ ] 用户提交任务时自己指定(推荐)
- [ ] 系统对固定流程预先配置好
- [ ] 全部输出,用户事后挑选

**3. 什么时候拿到?**
- [ ] 任务完成后一起下载(推荐)
- [ ] 运行中某一步完成就能下载

**4. 文件格式?**
- [ ] GeoTIFF / COG(推荐)
- [ ] NetCDF / Zarr(多维时间序列)
- [ ] 矢量类还需 GeoJSON / GeoPackage

**5. 单次任务中间结果大概多大?**
- [ ] 小于 1 GB
- [ ] 1 GB – 50 GB
- [ ] 50 GB 以上

**6. 是否需要 STAC 目录?**
- [ ] 不需要,给文件列表即可
- [ ] 需要:每次任务的结果自带 STAC 描述(OpenEO 批处理已支持,成本低)
- [ ] 需要:还要入库到 STAC 服务,供检索和跨任务复用(需额外部署,工作量大)

**7. 中间结果能否作为下一次任务的输入复用?**
- [ ] 需要
- [ ] 不需要,只用于查看/下载

**8. 谁可以下载?**
- [ ] 仅提交任务的本人(推荐)
- [ ] 同团队/项目成员
- [ ] 所有登录用户

**9. 保留多久?**
- [ ] 7 天
- [ ] 30 天(推荐)
- [ ] 手动删除前一直保留

---
**默认建议(PM 无明确意见时):** 用户自选输出步骤,任务完成后下载 COG,仅限本人,保留 30 天;STAC 目录入库和"运行中下载"放二期。
